# Security reports

Do not include passwords, tokens, databases, private configuration, or real
infrastructure details in public issues. Report vulnerabilities through this
repository's Security tab using **Report a vulnerability**. If private reporting
is unavailable, contact the maintainer through their GitHub profile before
sharing sensitive details.

Only explicitly configured proxy peers may supply client-IP headers. Keep
backend credentials and session-encryption keys private, and deploy public
instances behind HTTPS. See the README for the threat model and limitations.
